# CTAG2F90D 抓取控制链路验证（2026-09-17）

## 结论

本次定位到明确的固件兼容性问题：控制器实际为 V1.7.0；睿尔曼官方版本说明在 **V1.7.3** 条目中列出“新增读写末端生态设备寄存器接口”。当前抓取实现依赖这些接口，不能在 V1.7.0 上验收限力或力控闭合。

来源：[睿尔曼版本变更说明](https://develop.realman-robotics.com/robot/releaseNotes/releaseNotes/)、[末端工具 JSON 协议](https://develop.realman-robotics.com/robot/json/endeffector/)。当前在线文档不是 V1.7.0 的功能清单。此前没有核对接口引入版本，误将兼容性问题归为一般的“回读未验证”，在此更正。

## 实机证据

- RM75-BI，控制器 V1.7.0，build 2025/03/10，末端 RM Plus 115200。
- 设备 ZX/id=1/type=1/dof=1，固件 V1.154。
- `get_rm_plus_base_info` 正常返回 `force:true, touch:false, force_up:[100]`。
- `get_rm_plus_state_info` 正常返回 `pos:[499], speed:[0], force:[0], dof_state:[2]`，无系统或自由度错误。
- 对寄存器 1000（长度11，官方示例）、1180（长度1和2）、1220（长度1和2）、1260、1270、1470 分别进行查询。8次查询都只收到 `get_state:true`，无 `plus_reg_data`；每次保持连接至少1秒检查后续响应。
- 原始请求/响应：MSI `work/grasp/verification_20260917/readback_matrix.json`。本轮没有寄存器写入、夹爪开合或机械臂运动。

## 后续处理

1. 请厂商按设备序列号提供支持生态寄存器接口的配套版本。V1.7.3发布说明列出的末端接口板为V1.9.9、API2为V1.1.3；这些是该版本的对照信息，不应在未核对实际硬件时直接升级。
2. 升级前备份控制器参数、工具/负载和坐标系；本次未升级固件，也未修改已接受的手眼标定数值。
3. 升级后重新读取软件、工具、Base和关节状态，确认与项目一致。当前代码仍会核对标定记录中的控制器版本，需经复核后更新兼容性记录，不能伪造旧记录。
4. 先验证寄存器实际回读和夹爪停止，再做空载/接触/力度测试；全部通过后才更新验收标记。

应用现在在执行流程开始阶段报告明确的固件兼容性错误；“读取夹爪状态”也显示版本和兼容性结论。默认执行模式只意味着允许按钮触发后通过检查的运动，不会在启动或跟踪时自动抓取。
